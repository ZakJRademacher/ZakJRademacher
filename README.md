### Excel export consolidation

A macro-free Excel Power Query workbook that merges recurring CSV exports, standardizes known column/date formats, skips identical repeats and separates corrections from accepted records. Source filename and record numbers make every output traceable. Native Excel refresh tests cover adding a file, unchanged inputs, an unsupported filename and restoring the baseline. Includes the workbook, sample data, Python reference checks, 16 tests and full handoff documentation.

### Commerce operations in Power BI

A native four-page report covering **99,441 historical Olist orders**. Interactive views compare delivery workload and rates, merchandise categories and data quality. Includes Python cleanup, SQLite reconciliation, a downloadable PBIX, editable model/report definitions and a refresh guide.

### Interactive sales explorer in Power BI

A native four-page dashboard over **9,800 Superstore sample lines across 48 monthly files**. Synchronized filters, a category ribbon, interacting change bars and product-to-source exploration support a monthly business review. Python/SQL validates exports before Power BI Refresh imports them. Includes a downloadable PBIX, editable source, supporting Excel/HTML reports, 38 tests, native DAX checks and an actual November-to-December refresh replay.

### Retail sales and data quality

An audit of **541,909 actual historical retail transaction lines**. Preserves source-row traceability, handles cancellations and missing customer IDs, and reconciles exact monetary totals across SQL reports. Includes an editable Excel review and documented duplicate sensitivity.

### Complaint intake operations

A reporting workflow using **903,983 historical complaint records**. Validates IDs and dates, produces SQL summaries and an Excel review queue, and preserves reviewer notes by complaint ID. The handoff defines routing intervals, review rules and the limits of the selected examples.
