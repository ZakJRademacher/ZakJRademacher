# Security policy

## Supported versions

Not applicable. This repository holds my GitHub profile page and the scripts that build it, and has no releases. Fixes go to `main`.

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

1. Go to the repository's **Security** tab and choose **Report a vulnerability**. This opens a private advisory that only the maintainer can see.
2. Describe the problem, the affected file or workflow, and how to reproduce it.

You should get a reply within 7 days. Once a fix is in place, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Scope

These are in scope:

- The scripts in `tools/` and the workflows in `.github/`.
- Anything that exposes repository secrets or private information through this repository.

Problems in a listed project belong in that project's own repository.
